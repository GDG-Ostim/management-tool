# Teknik Kaynaklar

Teknik tercihleri doğrulamak için Context7 resolve → query akışı kullanıldı (2026-10-13). Bu not kaynak dizinidir; sürüm kilidi değildir. Kodlama sırasında ilgili API güncel dokümandan yeniden doğrulanır.

- [Better Auth kurulum](https://www.better-auth.com/docs/installation): better-sqlite3 doğrudan adapter.
- [Better Auth Express](https://www.better-auth.com/docs/integrations/express): handler body parser'dan önce; Express 5 named wildcard.
- [Better Auth email/password](https://www.better-auth.com/docs/authentication/email-password): kapalı kayıt ve password reset.
- [Better Auth admin](https://www.better-auth.com/docs/plugins/admin): sunucu taraflı kullanıcı oluşturma.
- [Better Auth React client](https://www.better-auth.com/docs/concepts/client): React istemcisi.
- [better-sqlite3 API](https://github.com/WiseLibs/better-sqlite3/blob/master/docs/api.md): transaction, timeout ve backup.
- [better-sqlite3 performans](https://github.com/WiseLibs/better-sqlite3/blob/master/docs/performance.md): WAL.
- [Express 5 API](https://expressjs.com/en/5x/api.html): middleware, static dosyalar.
- [shadcn/ui Vite](https://ui.shadcn.com/docs/installation/vite): React + TypeScript SPA.
- [Resend + Better Auth](https://resend.com/docs/send-with-better-auth): şifre e-postası.
- [Resend Express](https://resend.com/docs/send-with-express): sender ve hata işleme.
- [GitHub CLI Projects](https://cli.github.com/manual/gh_project): project scope, proje oluşturma/link/item.
- [Codex AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md): repo talimat keşfi.

Doküman örnekleri güvenlik/iş akışı kararının yerine geçmez; komite yetkileri uygulamamızda tanımlanır.
